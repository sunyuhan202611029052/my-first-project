# my-first-project
# 英语学习困难统计小工具
> 统计问卷里同学们英语学习遇到的困难，计算各类问题占比

## 🎯 这个项目做什么
读取调研问卷数据，统计不同英语学习困难的人数，自动计算百分比，打印统计结果，方便我们分析学生英语学习痛点。

## 🛠️ 怎么运行
1. 环境：Python3（系统自带，无需额外安装库）
2. 运行命令：`python main.py`

## 📑 功能 / 特点
- 内置问卷原始调研数据
- 统计每一类学习困难的人数
- 自动计算各类困难所占百分比
- 在控制台输出清晰的统计报表

## 📈 下一步 / 想做的
- 后续可以增加从外部csv文件读取数据
- 增加排序功能，自动把人数最多的困难排在最前面
